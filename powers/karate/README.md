# Karate — deterministic test evidence

Run API, browser and business-rule checks against what you build, and get back deterministic evidence: coverage, requirement traceability, and one shareable report.

Every check declares the acceptance criterion it verifies, so the result says which criteria have a passing check behind them and which do not — derived deterministically, with no model in the loop.

## Install

Import the power from GitHub:

<https://github.com/karatelabs/karate-agent-examples/tree/main/powers/karate>

It connects to a Karate Agent you run yourself on port 4444 and needs a Karate Labs runtime license; the power's onboarding walks the agent through starting the server.

## Privacy

[Privacy Policy](https://karatelabs.io/privacy-policy). The MCP server is your own instance: source, tests and results stay in your workspace, no telemetry is sent to Karate Labs, and the license is validated offline.
